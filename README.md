# NEON BREAKER

ブラウザで遊べるシンプルなブロック崩しゲームです。HTML / CSS / JavaScript の単一ファイル（`index.html`）だけで動作し、外部ライブラリは不要です。

## 公開URL

https://haruo6900.github.io/neon-breaker/

## 遊び方

- パドル操作: マウス / タッチ / `←` `→` `A` `D`
- 発射: クリック / タップ / `Space`
- 一時停止: `P` / `Esc`
- リスタート: `R`
- サウンド切替: `M`

ブロックをすべて壊すとレベルクリアです。ライフは3つ。ハイスコアはブラウザの localStorage に保存されます。

## 特徴

- スマートフォンの縦向き・横向きに自動対応
- タッチ操作、セーフエリア、画面回転に対応
- 依存ライブラリなし・オフライン動作
- WebAudio による効果音、パーティクル、残像などの演出

## 2人対戦版: NEON DUEL

`duel.html` を開くと、1台の画面で2人が対戦できるピンポン風ゲームが遊べます。

- P1: `W` / `S`
- P2: `↑` / `↓`
- タッチ: 画面の左半分 / 右半分をドラッグ（2人同時操作可）
- 一時停止: `P` / `Esc`、リスタート: `R`、サウンド: `M`
- 先に7点取った方が勝ち
- ボールは打つたびに少しずつ加速し、パドルに当てた位置で角度が変わります

`duel.html` も単体で動作し、外部ライブラリは不要です。

## ローカルで開く

`index.html`（1人用）または `duel.html`（2人対戦）をブラウザで直接開くか、任意の静的サーバーで配信してください。

```sh
npx serve .
```
