# NEON BREAKER / NEON DUEL / HUMAN DERBY

ブラウザで遊べるゲーム集です。

- `index.html` … 1人用ブロック崩し **NEON BREAKER**
- `duel.html` … 2人対戦ピンポン **NEON DUEL**（1台対戦 / 別端末オンライン対戦）
- `derby.html` … 3D人間ダービー **HUMAN DERBY**（1人用 / スマホ・PC対応）

- NEON DUEL（2人対戦）: https://haruo6900.github.io/neon-breaker/duel.html

## HUMAN DERBY（3D人間ダービー）

8人の走者が400m / 800m / 1200mのトラックを駆け抜ける、3Dの人間ダービー＆ベッティングゲームです。スマホのタッチ操作とPCの両方に対応しています。

- **走者の名前は毎レース抽選**。カレーパン、ハンカチヤマダ、モバイルバッテリーなど、面白いカタカナ名の走者たちが入れ替わりで登場します。
- **天候は毎レース変化**。晴れ / 曇り / 雨 / 強風 / 猛暑 / 濃霧の6種類で、走路コンディションと有利な能力値が変わります。
- **距離も毎レース変化**。400m / 800m / 1200mから抽選され、長距離ほどスタミナと持久力特性が重要になります。距離に応じてデフォルトの再生速度も変わります。
- **コンディションも毎レース変化**。絶好調から絶不調までの5段階で、同じ能力値の走者でも調子が変わります。
- 走者ごとに **スピード / スタミナ / パワー / 技術** の能力値と、天候や展開で効果を発揮する **特性** があります。
- 選抜画面は **3Dパドック＋横並びカード**。選択中の走者を大きく表示し、絶好調はガッツポーズ、不調はうなだれたポーズでコンディションを表現します。
- **単勝 / 複勝 / 3連単 / 三連複** の4種類でベットできます。3連単は着順どおり、三連複は3着以内の3人を順不同で当てます。
- レース中は **追走 / 斜め前 / 上空** の3カメラを切り替え可能。斜め前は競馬中継のように前方からフィールド全体を見る視点です。`CAM` ボタンまたは `C` キーで切り替えられます。
- **ゴール16m前からサイドの固定フィニッシュカメラに強制切り替え**。1着・2着が2.8m以内の接戦なら、自動でスローモーション演出が入ります。競り合っている1〜3着グループがゴールした時点でスローモーションは解除され、残りの走者は通常速度でゴールします。
- 実況つきの3Dレース、ゴール演出、結果発表、コインの自動保存に対応しています。

### HUMAN DERBY の遊び方

1. 3Dパドックの走者とカードを見て、オッズ、コンディション、特性、能力値を比較して選びます。カードの色・ポーズ・3Dの立ち姿で調子がわかります。
2. ベットの種類と賭け金を選びます。
   - **単勝**: 選んだ走者が1着なら的中。
   - **複勝**: 選んだ走者が3着以内なら的中。
   - **3連単**: 1着・2着・3着を順番どおりに当てる。走者をタップした順に1着→2着→3着になります。3人未満ではスタートできません。
   - **三連複**: 3着以内に入る3人を順不同で当てる。3人を選ぶとスタートできます。
3. 「レーススタート」で3Dレースを観戦。レース中は `1× / 2× / 3× / 4×` の速度変更、`早送り` が使えます。800mは2×、1200mは3×が初期速度です。
4. 的中すると「賭け金 × オッズ」が払い戻されます。コインはこの端末の localStorage に自動保存されます。
5. コインが100未満になると、次のレース前に救済として500コインが付与されます。

- 3連単・三連複のオッズは、選んだ3人の勝率と組み合わせから算出されます。
- ベットせずに観戦することもできます。
- レース画面右上の `追走 / 斜め前 / 上空` ボタンでカメラ視点を切り替えられます。
- ゴール前は自動でフィニッシュカメラに切り替わります。接戦時は `SLOW MOTION` 表示とともにスローモーションになります。
- 難易度やステージはなく、天候・コンディション・名前の変化を読みながら連戦するゲームです。

> 3D描画に Three.js（CDN）を使用しています。初回読み込み時はインターネット接続が必要です。コインや成績はブラウザ内にのみ保存され、サーバーには送信されません。

## NEON DUEL の遊び方

### 別端末でオンライン対戦

1. 2人とも同じ `duel.html` のURLを開きます。
2. 片方が「オンライン対戦」→「ルームを作る」を選びます。
3. 表示された5文字のルームコードを、もう片方に伝えます。
4. 相手は「オンライン対戦」→ コードを入力 →「参加」を押します。
5. ホストがP1（左）、ゲストがP2（右）です。先に7点取った方が勝ちです。

- 自分のパドルは、ゲーム画面を上下にドラッグして操作します。オンライン対戦では画面のどこをドラッグしても自分のパドルが動きます。
- 一時停止はヘッダーの `❚❚` ボタン、または `P` / `Esc` キーです。
- リスタートは `R`、サウンド切替は `M` キーでも操作できます。
- 相手が切断すると通知が出ます。再戦も同じルームからできます。

### 1台で対戦

タイトル画面の「1台で対戦」を選びます。

- P1: `W` / `S`
- P2: `↑` / `↓`
- タッチ: 縦持ちでは画面下のパッドを上下にドラッグ（左半分=P1 / 右半分=P2）。横持ちでは画面の左半分 / 右半分をドラッグします（2人同時操作できます）

## iPhone で遊ぶ

- Safariで開いてください。**縦持ち**のまま、ゲーム画面の下にある大きな縦パッドを上下にドラッグして操作できます。
- 横向きにした場合は、従来どおりゲーム画面全体を上下にドラッグして操作できます。縦向きのほうが指で操作しやすく、画面も見やすいレイアウトです。
- Safariの「共有」→「ホーム画面に追加」で、全画面に近い状態で起動できます。
- ノッチ、ホームインジケーター、セーフエリアに対応しています。ページのスクロールやダブルタップ拡大は抑止しています。
- ゲーム中はヘッダーの `❚❚` で一時停止できます。iPhoneでは全画面ボタンは表示されません（Safariの全画面API非対応のため）。

### iPhoneで開くためのホスティング

iPhoneからは `file://` で開くのが難しいため、HTTPSでホストしたURLを開いてください。

- GitHub Pages
- Netlify
- Cloudflare Pages
- その他の静的ホスティング

`index.html`、`duel.html`、`derby.html`、`manifest.webmanifest`、`icon.svg`、`icon-512.png`、`apple-touch-icon.png` を同じディレクトリに置いてください。`derby.html` は Three.js をCDNから読み込むため、初回はオンライン環境で開いてください。

## オンライン対戦の仕組み

- 通信には **MQTT over WebSocket** を使用しています。
- ブローカーは公開リレーの `wss://broker.emqx.io:8084/mqtt` です。
- ルームコードは5文字です。ホストとゲストで別々のトピックを使い、自分のメッセージが自分に戻らないようにしています。
- ホストがボールの物理演算とスコアを管理し、ゲストは入力と自分のパドルを送信します。
- 接続にはインターネット接続が必要です。ローカルの1台対戦はオフラインでも遊べます。
- オンライン対戦時のみ、MQTT.js 5.10.1 をCDN（jsDelivr / unpkg）から遅延読み込みします。

> 公開MQTTブローカーを利用しています。ゲームの座標データ以外は送信しませんが、ルームコードは秘密情報ではありません。個人情報や機密情報は送らないでください。第三者が同じコードを使わないよう、ランダムなコードを利用してください。

## ローカルで開く

`index.html`（1人用）または `duel.html`（2人対戦）をブラウザで直接開くか、静的サーバーで配信してください。

```sh
npx serve .
```

- PC: `http://localhost:3000/duel.html`
- iPhone（同じWi-Fi）: `http://<PCのIPアドレス>:3000/duel.html`
- HUMAN DERBY: `http://localhost:3000/derby.html`（スマホでも同じURL）

LAN配信の場合は、PCのファイアウォールでポートを許可してください。オンライン対戦ではCDNとMQTTブローカーへの接続が必要です。iPhoneで安定して遊ぶにはHTTPSホスティングを推奨します。

## NEON BREAKER（1人用）

- パドル操作: マウス / タッチ / `←` `→` `A` `D`
- 発射: クリック / タップ / `Space`
- 一時停止: `P` / `Esc`
- リスタート: `R`
- サウンド切替: `M`

ブロックをすべて壊すとレベルクリアです。ライフは3つ。ハイスコアはブラウザの localStorage に保存されます。
